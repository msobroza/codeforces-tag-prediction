Focus tags come with others

89% also carry a non-focus tag, e.g. greedy, dp

Over all 37 tags, a problem carries 2.8 tags on average, most often 2 or 3, up to 11. Over the 8 focus tags the picture changes: 2,304 problems carry none of them, 2,019 exactly one, 596 two, and only 63 three or more. So among the problems that have a focus tag, three quarters have exactly one, and the mean is 1.27. Focus tags rarely come alone: 89% of these problems also carry a non-focus tag such as greedy, implementation or dp, and the more focus tags a problem has, the more tags it has overall. The consequence for the models: each tag is a separate yes or no decision with its own threshold, there is no fixed number of tags to output, and predicting nothing is a valid and frequent answer.
