Predicting
Codeforces tags

Multi-label classification of 4,982 exercises

13 methods · one protocol · one command line

October 2026

Ph.D. Max Sobroza

The task: given a Codeforces exercise, predict which of eight focus tags it carries. I built and compared 13 tagging methods under the same protocol, from a label prior to zero-shot LLMs, and wrapped them in one command line.
