★ CLI default · † best dev F1 · Dev F1: out of fold · n/d: size not disclosed by the provider

Test F1 is the test macro F1, scored once per method; Dev F1 is the dev out-of-fold macro F1, the score every choice is made on. The fine-tuned column asks whether training changes the weights of a pretrained network. Only the two ModernBERT methods are fine-tuned: all weights of ModernBERT-base, or a rank-32 LoRA adapter on ModernBERT-large. F2LLM keeps its encoder frozen and trains a linear head. The API methods learn nothing, except Jev's eight per-tag thresholds. TF-IDF is trained from scratch, with no pretrained model. Latency is the median of one prediction with the method loaded: ModernBERT and F2LLM on an RTX 2080 Ti GPU; on a CPU, F2LLM takes three to four seconds. The CLI default, jev-statement-code, has the best test score; descode2tag-json has the best dev score, 0.003 above it, but is 4.7 times slower, so the default stays Jev (ADR 0008).
