Rare tags, small test sets

So scores carry bootstrap intervals

37 tags exist in all, 2.8 per problem; the task statement asks for 8. math dominates with 28% of problems, probabilities has 92, so every tag weighs one eighth in the macro F1 and per-tag scores are reported. Every tag is a minority, so a 0.5 cutoff rarely fires: the first, untuned logistic regression goes from 0.19 to 0.61 macro F1 with thresholds chosen per tag on dev folds. 46% of problems have none of the 8 tags; they stay in as negatives, so a model must also learn to predict nothing. With 21 games and 18 probabilities problems in test, a few points of F1 on a rare tag are within the noise.
