The package flows left to right. Data reads the raw samples and cleans them; the split groups near-duplicate problems and freezes dev, test and the folds once. Every method plugs into one contract, a TaggingMethod with predict and save, registered in one table: fourteen are registered, thirteen are frozen. Evaluation and the CLI turn predictions into per-tag scores. Around it: tuning and tracking run the Optuna studies and mirror everything to MLflow; assets is the committed record, so nothing needs a paid call to be checked again; notebooks read only frozen files; the tests and eight ADRs pin the rules. Three rules hold everywhere: one contract for every method, heavy libraries off the prediction path, and a verify command that re-derives every frozen number.
