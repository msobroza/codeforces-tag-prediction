Model selection never touches the test set (ADR 0001). Every method is compared on dev out-of-fold macro F1: fitted on four folds, scored on the fifth, with per-tag thresholds chosen on the other folds. Tuning happens only on dev: TF-IDF's 200-trial study, ModernBERT tuned on one fold because a trial takes 5 to 20 minutes, F2LLM's grid studies. The zero-shot methods learn nothing, and Jev learns only its eight thresholds. Then each frozen method scores the 994 test problems once; the next slides report those test scores.
